# Vocitap 语音输入工具 - macOS 用户指南

欢迎使用 **Vocitap**！这是一个基于阿里巴巴 SenseVoiceSmall（ONNX 轻量版）模型的智能语音输入工具。它支持按住快捷键说话，并在松开后自动将语音转换为文字直接粘贴在光标处，且支持物理 USB 有线串口与专属硬件交互。

---

## 📦 打包与运行

为了在您的 macOS 系统上流畅运行并建立 `.app` 单文件应用程序，请根据以下说明进行简单打包和启动：

### 1. 本地一键打包
由于平台限制，在 Windows 设备上编译的二进制文件无法直接在 macOS 上启动。您需要将本项目拷贝到 Mac 电脑上，并在 Mac 终端中运行编译脚本：
- 打开 Mac 终端，定位至 `mac_app` 文件夹；
- 执行以下命令：
  ```bash
  chmod +x build_mac.sh
  ./build_mac.sh
  ```
- 编译完成后，会在当前目录下生成 **`Vocitap.app`** 应用程序包，直接双击运行即可。

### 2. 依赖自愈与启动
- **首次启动**：启动器会静默检测 Mac 本地 Python3 运行环境。如果缺失必要的运行依赖，程序会弹出“智能启动器”界面，通过 pip 自动为您配齐所需的依赖（如 `sherpa-onnx`、`PySide6`、`pyserial` 等）。
- **模型自动下载**：如果缺失 SenseVoice 模型，程序会引导您自动下载（模型大小约 233MB）。

### 3. 数据存放路径 (Application Support)
所有的配置和下载的模型都存放在 macOS 标准的偏好数据存储路径下：
- **路径**：`~/Library/Application Support/Vocitap` (即当前用户目录下的 Library/Application Support)
- **主要内容**：
  - `config.json`：存放您的语气词过滤、自启动、触发键等配置。
  - `runtime/`：**影子部署目录**。打包的 App 启动后，会自动把内置源码释放并定位至此文件夹下运行，保证版本热校准。
  - `models/`：模型文件夹。存放 `model.int8.onnx` 与 `tokens.txt`。

## 🔌 硬件（有线键盘/麦克风）连接指南

如果您搭配了有线硬件连接使用，请在 Mac 下完成以下配置：
*(注：该硬件固件已全面开源，您可前往制作、购买或刷写固件：[VoxTriple_Classic 开源仓库](https://github.com/elementchen/VoxTriple_Classic))*
1. 使用 USB 数据线将硬件连接至 Mac 电脑（若为 USB-C 接口请使用转接头）；
2. 点击系统菜单栏（托盘）中的 **Vocitap 图标**，选择 **“显示界面”**；
3. 切换至 **“硬件配置”** 选项卡；
4. 点击 **“扫描并刷新串口”**；
5. 在下拉列表中，选中您的设备名称。在 macOS 上串口设备通常以如下格式命名：
   - `/dev/cu.usbserial-XXXX` 或 `/dev/cu.wchusbserialXXXX`
6. 点击 **“连接设备”** 按钮。状态栏提示已连接即表示配置完成。

## 🔒 ⚠️ macOS 系统关键授权说明 (非常重要)

由于 macOS 具备严格的沙盒安全隐私机制，为了保证 Vocitap 能够正常录音并输入文字，您**必须**授予以下两项系统权限：

1. **麦克风权限**：
   首次录音时，系统会弹出“Vocitap 想要访问您的麦克风”的弹窗，请务必选择 **“允许”**。
2. **辅助功能（Accessibility）注入授权**：
   因为软件需要向当前光标模拟按 `Command+V` 来实现粘贴文字上屏，请手动在 Mac 的：
   - **“系统设置 -> 隐私与安全性 -> 辅助功能”** 列表中，找到 `Vocitap.app`（或正在运行的 `Python` 进程/终端）并勾选**启用**。
   *若不授予此权限，在松开按键后文字将无法自动粘贴在光标处。*

## 🚀 语音录入使用方式

1. 在任意可编辑文本区（如备忘录、微信、浏览器输入框）中点亮光标；
2. 按住键盘上的 **`[左 Ctrl 键]`**（或您在软件面板中绑定的自定义按键）；
3. 对着麦克风开始说话；
4. **松开按键**，文字将在 0.5 秒内自动上屏。
