# Vocitap 语音输入工具 - Windows 用户指南

欢迎使用 **Vocitap**！这是一个基于阿里巴巴 SenseVoiceSmall（ONNX 轻量版）模型的智能语音输入工具。它支持按住快捷键说话，并在松开后自动将语音转换为文字直接粘贴在光标处，且支持物理 USB 有线串口与专属硬件交互。

---

## 📦 安装与运行

本软件采用**“单文件 EXE + 云端依赖补全 + 影子部署”**的设计方案。

### 1. 快速启动
- 双击目录下的 **`Vocitap.exe`** 即可直接运行。
- **首次启动**：如果您的 Windows 电脑缺失必要的 Python 运行库，程序会弹出一个“智能启动器”界面，通过 pip 自动为您配齐所需的依赖（如 `sherpa-onnx`、`PySide6`、`pyserial` 等），此过程通常只需几十秒。

### 2. 存放位置与重要路径 (AppData)
为了保持项目目录的纯净，软件在运行期间所有的配置、缓存和模型数据都存放在系统专用的 AppData 目录下：
- **路径**：`%APPDATA%\Vocitap`（在资源管理器中输入回车，一般位于 `C:\Users\您的用户名\AppData\Roaming\Vocitap`）
- **子目录说明**：
  - `config.json`：存放您的自启动设置、剔除语气词、键盘映射等配置。
  - `runtime/`：**影子部署目录**。软件在运行时会自动把代码释放到此处用系统 Python 执行，以保证最新特性的快速热更新。
  - `models/`：**模型存放处**。首次运行如果缺失模型，软件会引导您自动下载（模型大小约 233MB）。您也可以将手动下载好的 `model.int8.onnx` 与 `tokens.txt` 放入该文件夹。

## 🔌 硬件（有线键盘/麦克风）连接指南

如果您搭配了 ESP32 有线键盘硬件使用，请按照以下步骤配置：
1. 使用 USB 数据线将硬件连接至 Windows 电脑的 USB 接口；
2. 右键点击系统右下角的 **Vocitap 托盘图标**（彩色小图标），选择 **“显示界面”** 打开控制面板；
3. 切换到 **“硬件配置”** 选项卡；
4. 点击 **“扫描并刷新串口”**，在下拉菜单中选中您的设备对应的 COM 端口（例如 `COM3`）；
5. 点击 **“连接设备”** 按钮。状态栏显示“已连接”后，即配置成功。
   *注：软件会记住您最后一次连接成功的端口，下次启动时如果设备已插入，会自动进行物理重连。*

## 🚀 语音录入使用方式

1. 确保您的默认录音设备（麦克风）已正常启用；
2. 在任意文本输入框（如微信、Word、网页）中将光标定位好；
3. 按住键盘上的 **`[左 Ctrl 键]`**（或通过托盘菜单自定义的其他触发键）；
4. 开始说话；
5. **松开按键**，文字将在 0.5 秒内自动上屏粘贴至光标处。
